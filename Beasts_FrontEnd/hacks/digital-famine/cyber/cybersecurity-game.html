🛡️ Interactive Coding Adventure

Cybersecurity Learning Game: Alien Invasion

Code through three escalating missions to rebuild Earth's defenses, lock down vulnerable systems, and seal the vault that hides the Sacred Page. Each mission focuses on a core cybersecurity concept through hands-on practice.

🧠 Overview

This narrative-driven experience blends database work, secure coding, and cryptography. Players earn a vault PIN by completing automated checks in every mission and use it to reclaim the Sacred Page that ends the invasion.
